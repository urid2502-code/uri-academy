# האקדמיה של אורי

אתר לימוד ותרגול אינטראקטיבי בעברית: מסלול מהיסוד ועד רמת **Senior Full Stack Engineer**.
המונחים המקצועיים כתובים באנגלית, וההסברים בעברית.

## הרצה

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # בדיקת טיפוסים + בנייה ל-dist/
```

## מסכי הלמידה

- **מצב מיקוד** (`#/focus/m1/l1`): כפתור "מצב מיקוד" בכל שיעור פותח קריאה בלי סרגל צד, עם אינדיקטור התקדמות וקטע נוכחי. לוח הצד כולל **Deep Notes** (הערות אישיות לכל שיעור, נשמרות ב-`localStorage`) ו-**Timeline of Mastery** (ציר מודולים מתקפל עם סימון שיעורים שהושלמו). כל התרגילים, הקוד והמבחנים זהים לשיעור הרגיל, כי שניהם משתמשים ב-[LessonBody.tsx](./src/components/LessonBody.tsx).
- **Thought Streams** (`#/community`): מרחב אישי למחשבות, שאלות ו-Socratic Circles, עם לייקים ותגובות שנשמרים רק במכשיר שלך (`uri-academy:community:v1`). אין שרת, חשבון או תוכן מומצא.
- דפי המסלול (`#/course/fullstack`, `#/course/java`) שומרים התקדמות ושיעור אחרון בנפרד. שלוש לשוניות מציגות את תוכנית הלימודים, מפת הכישורים ומדריך וכלי הלמידה. איפוס ההתקדמות באזור המתקפל בלשונית המדריך חל על כל המסלולים.
- תוכנית הלימודים מציגה את כל שלושת השלבים ברצף, בלי תפריט סינון נוסף. פותחים מודול אחד בכל פעם כדי להגיע לשיעורים, או נכנסים לסקירת המודול עם מטרות הלמידה וההתקדמות.
- בשיעור יש תוכן עניינים קבוע במסך רחב, ותפריט נפתח בטלפון. דוגמאות הקוד, התרגילים, הפתרונות והמבחנים נשארים באותו מסך.
- **מונחים חשובים** מציגים את המונח, התרגום וההגדרה בתוך השיעור, ללא מעבר אוטומטי למילון. הרשימה מסודרת בשתי עמודות שוות במסך רחב ובעמודה אחת בטלפון; מונח אחרון ללא בן זוג נפרס לרוחב השורה.
- כותרות שלבי השיעור נקיות מסרטוני לולאה דקורטיביים. התרשימים האינטראקטיביים ומעברי הניווט נשארים זמינים.
- [CourseHeader.tsx](./src/components/CourseHeader.tsx) משותף למסלול, למודולים ולתצוגות הקורסים שבפיתוח. מסכי הלמידה מכבדים את בחירת המצב הבהיר/כהה.

## Hero וקרוסלת הקורסים

לא נדרשות תלויות או הגדרות נוספות מעבר לפקודות ההרצה למעלה.

- [CourseHero.tsx](./src/components/CourseHero.tsx) מחזיק `position` רציף. `activeIndex` מחושב ב-Modulo לפי מספר הקורסים, וקובע גם את הכרטיס המודגש, גם את תמונת הרקע וגם את יעד כפתור הפעולה.
- גרירה בעכבר, Swipe וחצים פועלים בלולאה אינסופית: מהקורס האחרון חוזרים לראשון, ומהראשון לאחרון. בחירה בכרטיס או בנקודת ניווט עוברת במסלול הקצר; מקשי `Home` / `End` בוחרים את הראשון / האחרון.
- `ResizeObserver` מודד את רוחב הכרטיס והאזור הזמין. היסט המסילה מחושב כך: `viewportWidth / 2 - cardWidth / 2 - position * (cardWidth + gap)`. `LoopSlot` ממקם מחדש כל כרטיס מחוץ לתצוגה לפי מיקום המסילה, בלי לשכפל כרטיסים או מזהי נגישות. `Motion` מנפיש את המיקום; `AnimatePresence` מבצע Cross-fade לתמונת הרקע.
- [course-visuals.ts](./src/components/course-visuals.ts) מכיל איורי SVG מקוריים ומקומיים. לשינוי האיור של סוג קורס, משנים את `artByIcon`. אין בקשות לשרת תמונות חיצוני.
- תמונת הרקע מציגה את כל האיור ביחס הממדים המקורי, ומתמזגת בשוליים עם הרקע. התמונות בכרטיסים משתמשות באותו יחס ממדים כדי לא לחתוך תוכן.
- תוכן הקורסים מגיע מ-[courses.ts](./src/content/courses.ts). קורסים שטרם נפתחו מסומנים במפורש "בקרוב", והכפתור מוביל לסילבוס, לא לשיעור שאינו קיים.
- ההנפשות מכבדות `prefers-reduced-motion`. הקרוסלה אינה מתקדמת אוטומטית ואינה משנה ציונים או התקדמות לימודית.
